## أول إعداد مرة واحدة
### 1) إنشاء مشروع Supabase
أنشئ مشروعاً جديداً في Supabase.

### 2) إعداد قاعدة البيانات والتخزين
افتح SQL Editor في Supabase والصق محتوى:
`supabase_setup.sql`
ثم اضغط Run.

### 3) إنشاء حساب المطور
في Supabase:
Authentication → Users → Add user
أنشئ بريد وكلمة مرور خاصين بك.

الـSQL الموجود يجعل **أول مستخدم يتم إنشاؤه** هو المطور الوحيد.
بعد إنشاء حسابك، يُفضّل تعطيل التسجيل العام من إعدادات Authentication حتى لا يستطيع أحد إنشاء حساب جديد.

### 4) أخذ بيانات المشروع
من Supabase:
Project Settings → API
خذ:
- Project URL
- anon public key

ضعهما داخل:
`js/config.js`
في:
- `supabaseUrl`
- `supabaseAnonKey`

**ممنوع** وضع Service Role Key داخل الموقع.

### 5) ارفع الملفات على GitHub
ارفع محتويات هذا المجلد إلى مستودع GitHub Pages، وليس ملف ZIP نفسه.

بعدها:
- الموقع: `index.html`
- لوحة المطور: `admin.html`

## طريقة الاستخدام بعد الإعداد
1. افتح `admin.html`.
2. سجل الدخول بحساب المطور.
3. اسحب الصورة إلى خانة شغلنا أو آخر العروض أو آخر الإضافات.
4. الصورة تترفع إلى Supabase.
5. تظهر فوراً في الموقع لكل الزوار.
6. لو رفعت صورة جديدة لنفس الخانة، القديمة يتم حذفها واستبدالها بالجديدة.

## ملاحظة
GitHub Pages لا يخزن الصور التي ترفعها من المتصفح. Supabase Storage هو الذي يخزنها، لذلك الصور تظل موجودة وتعمل من أي جهاز.
